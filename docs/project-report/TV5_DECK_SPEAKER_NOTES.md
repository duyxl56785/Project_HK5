- **“Ảnh minh chứng lấy từ đâu?”** Từ screenshot thật của run trên main đủ gate, lưu theo case trong `reports/minh-chung-kiem-thu/`, kèm SHA256 và raw HTTP/JUnit/log tương ứng. Không tạo ảnh màn hình giả.
